# Проект «Мини-Склад» (Главы 1–5)
Учебная конфигурация 1С с минимальным контуром учёта.

### Что внутри:
* **Подсистема:** Мини-Склад
* **Справочники:** Товары, Контрагенты
* **Документы:** Поступление, Реализация
* **Регистры:** Остатки товаров (базовые движения прихода и расхода)

### Как открыть:
1. Создайте пустую информационную базу в 1С.
2. Откройте её в режиме Конфигуратора.
3. Нажмите *Конфигурация -> Загрузить конфигурацию из файлов...* и выберите папку `src` из этого репозитория.
4. Нажмите **F7** для обновления базы данных.

## Неделя 2
- Разработан аналитический отчет "Обороты по товарам" на базе СКД.
- Создана печатная форма накладной для документа "Реализация".
- Выполнен аудит и траблшутинг интеграционного модуля КБ99 в среде УТ 11.5.

## Неделя 3
- Внедрено автоматическое списание себестоимости по партиям закупки из регистра остатков `ОстаткиТоваров`.
- Документ «Реализация» списывает остатки и фиксирует объемы продаж в оборотном регистре `Продажи`.
- Отчет «Обороты по товарам» переведен на таблицу `ОстаткиИОбороты` и настроен в виде дерева (Товар -> Партия) для анализа партий закупки.

## Неделя 4
- Добавлен механизм множественного подбора товаров в документах "Реализация" и "Поступление" (через передачу параметров формы выбора на клиенте).
- Реализован автоматический расчет сумм строк в табличных частях документов при изменении цены или количества.
- Настроено условное оформление списков: непроведенные документы визуально выделяются тускло-серым цветом, а строки с остатком менее 2 штук подсвечиваются синим.

- Исправлен отчет по остаткам: осуществлен переход с таблицы "ОстаткиИОбороты" на чистую виртуальную таблицу "Остатки" с ограничением периода на конец дня (`КонецПериода(&ДатаОтчета, "ДЕНЬ")`) и выводом точной даты партии.
