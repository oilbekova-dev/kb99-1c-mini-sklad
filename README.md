# Проект «Мини-Склад» (Главы 1–5)
Учебная конфигурация 1С с минимальным контуром учёта.

### Что внутри:
* **Подсистема:** Мини-Склад
* **Справочники:** Товары, Контрагенты
* **Документы:** Поступление, Реализация
* **Регистры:** Остатки товаров (базовые движения прихода и расхода)

### Как открыть:
1. Создайте пустую информационную базу в 1С.
2. Откройте её в режиме Конфигуратора.
3. Нажмите *Конфигурация -> Загрузить конфигурацию из файлов...* и выберите папку `src` из этого репозитория.
4. Нажмите **F7** для обновления базы данных.
